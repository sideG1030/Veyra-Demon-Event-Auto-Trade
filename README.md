Tempermonkey script for Veyra The Black Crown Ascends event. The trade script will be updated as new trade events are added to the game.

Currently, the script has 2 modes:

'Planned/Future-aware'

The script plans the mest total gain in silver for the rest of the server day and automatically executes it.
Requires the user to have enough silver to buy the needed resources, aka, you need to be limited by time/weight.

'Immediate/Guarded'

The script just buys and sells the best resource it can right now. It can be used with any silver amount and its main function is to get enough capital to start using 'Planned' mode.
